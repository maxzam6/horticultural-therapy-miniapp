## 1. 阶段唯一目标

本阶段只完成答辩核心体验的后半程：

```text
P08 五感花园
→ P09 多肉种植体验详情
→ P10 体验任务
```

完成后，P01 首页至 P11 自然印记必须能够在 Mock 模式下连续运行，不依赖云开发、后台、真实图片上传或真实微信授权。

## 2. 执行方式：混合模式

本阶段不是纯并行，也不是全程串行。

```text
C009 契约 Review（串行，先完成）
↓
A032 / B040 / B042 / T032（并行）
↓

先合 B，后合 A（串行集成）
```

## 5. C009 Session / Record 契约冻结

C009 必须在页面编码前先确认，后续不得各自创建临时字段。

### 5.1 路由参数

```text
P08 → P09：id=courseId
P09 → P10：sessionId
P10 → P11：recordId
P11 → P12：使用 Tab 导航，不传新 Record
```

- `id`、`sessionId`、`recordId` 名称不得修改。
- 动态参数写入时使用 `encodeURIComponent`，读取时使用 `decodeURIComponent`。
- P11 不得用 `courseId` 或 `sessionId` 代替 `recordId`。

### 5.2 课程详情契约

沿用现有 `course-succulent`，补齐：

```js
{
  id,
  sense,
  senseName,
  title,
  subtitle,
  cover,
  duration,
  description,
  materials: [],
  safetyTips: [],
  mindfulnessPrompt,
  steps: [
    { id, title, description, image }
  ],
  status
}
```

- 多肉种植提供完整介绍、材料、安全提示和 4–6 个步骤。
- 专业内容仍是可替换 Mock，不声称已通过护理或园艺专业审核。
- 其他四门课程只保证共用 P09 模板可进入并显示友好占位，不要求本阶段补齐全部步骤。

### 5.3 Session 契约

```js
{
  id,
  courseId,
  status: 'active' | 'completed',
  currentStep,
  startedAt,
  completedAt,
  recordId
}
```

- P09 点击开始时通过 Store/Adapter 创建 Session。
- P10 只接收 `sessionId`，课程从 Session 的 `courseId` 获取。
- 页面不得自行拼接 `mock-session-*`。

### 5.4 Record 契约

继续使用第三阶段冻结字段：

```js
{
  id,
  sessionId,
  userId,
  courseId,
  courseTitle,
  sense,
  mood,
  feeling,
  imageUrl,
  completedAt,
  duration,
  growthIdentity
}
```

裁决：本阶段代码统一使用 `mood` 和 `feeling`。UI 仍显示“心情”和“我的感受”；不再新增 `emotion`、`reflection` 别名，避免和评估维度 `emotion` 混淆。

### 5.5 幂等规则

- 同一个 `sessionId` 第一次完成时创建一个 Record。
- 再次点击完成、返回重进或重复调用完成接口时，返回已有 Record。
- 已完成 Session 的 `recordId` 不得变化。
- P10 跳转 P11 后，P11 只读取该 `recordId`。
- P11 不创建、复制或补写另一条 Record。

### B042 Record 生成与幂等

- 自检至少覆盖：Session 字段、课程步骤、首次完成、重复完成返回同一 `recordId`。

验收：同一 Session 连续完成两次，Record 数量只增加一次。
