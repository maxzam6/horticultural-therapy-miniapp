# v1.3 云端数据与权限契约

> 2026-09-14；实施规格，尚未部署。产品边界见 [PRD v1.3](product/园艺疗法小程序_PRD_v1.3_社区与后台增量修订.md)。接口名为本项目约定，并非平台现成 API。

> 2026-09-15 实施更新：本地实现与联调已完成，云端未部署。物理集合结构和实际 RPC 名称的落地差异见 [运行与验收说明第 7 节](12_社区后台运行与验收说明.md#7-与前期契约的实现对应)；下文逻辑数据和权限规则仍适用。

## 1. 数据分工与代码接入

| 数据 | 存放位置 | 写入与读取责任 |
|---|---|---|
| 10 题、评分公式 | 现有源码 | 本轮不改算法 |
| 档案、测评、活动会话、体验 Record | Mock 仍用旧键；云模式按真实成员 ID 隔离本地键 | 保持 Store → Adapter → Storage |
| 云端身份、公开昵称 | users | 微信身份由云函数获取；成员仅更新自己的昵称 |
| 课程和版本 | courses、course_versions | 后台写，小程序读已发布版本 |
| 私密日记 | journal_entries | 本人读写，不在社区查询中返回 |
| 体验分享副本 | experience_shares | 仅主动分享时创建，本人管理 |
| 公开内容、互动 | community_posts、post_revisions、post_likes、post_comments | 云函数统一权限与状态判断 |
| 官方身份、管理授权 | official_accounts、admin_roles | 仅超级管理员管理授权 |

新增 `cloud` 适配模式，保留 `mock` 模式。社区/日记/身份分别有 Store，页面不直接读 Mock、Storage 或数据库。后台建议 `admin/` 独立 Vue 3/Vite 应用，云函数放 `cloudfunctions/`，共享请求与返回定义放 `shared/contracts/`；不在本轮升级现有小程序依赖。

课程云端读取需要修改现有 Adapter 的 `getCourses/getCourseById/startExperienceSession`：目前后者直接查 `mockCourses`，不能只换列表接口。活动会话增加 `courseVersionId/courseSnapshot`，`loadSession/completeSession` 从快照恢复步骤和时长；既有 Record 字段兼容。

本地旧会话首次恢复时用当前内置 Mock 补足快照，标记来源为旧演示数据。历史 Record 不重写数量、课程名称、时长。云模式切换账号清空内存 Store，再读取该账号的本地键；不认领未归属的旧记录。

## 2. 公共字段

- ID：服务端生成的 UUID/随机标识，不能仅使用 `Date.now()` 保证云端唯一。
- 时间：云端服务器时间，接口序列化为 ISO 8601 UTC；客户端时间只可作为用户记录时间，不能决定权限。
- `revision`：递增整数，用于阻止两位管理员或多设备互相覆盖；修改必须带 `expectedRevision`。
- `requestId`：客户端一次逻辑操作的 UUID，重试复用；服务端按操作者、动作、requestId 保存请求摘要与结果。相同 ID 不同载荷返回冲突。
- `ownerId/operatorId/authorType/officialAccountId/role/status/count` 等权限字段禁止直接接受客户端覆盖。
- DTO：接口对外返回的字段白名单。成员响应不含 OpenID、管理员 UID、审核原始回调和私人数据。

## 3. 集合定义

| 集合 | 主要字段 | 唯一性 / 索引 |
|---|---|---|
| users | id, openid, nickname, avatarFileId?, membershipStatus, revision, createdAt, updatedAt | openid 唯一；membershipStatus + createdAt |
| member_capacity | id=fixed, activeCount, limit=30 | 单一计数文档；批准与停用事务更新 |
| admin_roles | id=认证 UID, role(content_admin/super_admin), enabled | UID 唯一，不保存密码 |
| official_accounts | id, displayName, avatarFileId?, enabled | 第一版一个项目组账号 |
| courses | id, sense, sortOrder, status(draft/published/offline/archived), publishedVersionId?, revision | status + sortOrder + id |
| course_drafts | courseId, title, subtitle, coverFileId, duration, description, materials[], steps[], mindfulnessPrompt, safetyTips[], revision | courseId 唯一 |
| course_versions | id, courseId, version, 内容快照, publishedAt | courseId + version 唯一；版本不可变 |
| app_settings | id=public, defaultCourseId | 默认项必须为已发布可体验课程 |
| journal_entries | id, ownerId, title, body, imageFileIds[], createdAt, updatedAt, revision, deletedAt? | ownerId + createdAt + id |
| experience_shares | id, ownerId, localSourceKey, courseTitle, sense, mood, feeling, imageFileIds[], recordedAt, revision, deletedAt? | ownerId + localSourceKey 唯一 |
| community_posts | id, ownerId?, authorType(member/official), officialAccountId?, sourceType(journal/experience/official), sourceId, desiredPublished, moderationHold, status, currentRevisionId, publishedAt?, pinnedAt?, likeCount, commentCount, revision | sourceType + sourceId 唯一；status + pinnedAt + publishedAt + id |
| post_revisions | id, postId, version, title, body, imageFileIds[], sourceRevision, featuredPostIds[], reviewStatus, createdAt | postId + version 唯一 |
| post_likes | id, postId, memberId, createdAt | postId + memberId 唯一 |
| post_comments | id, postId, authorType, ownerId?, officialAccountId?, body, revision, status(pending/published/rejected/hidden/deleted), createdAt | postId + status + createdAt + id |
| content_reviews | id, targetType, targetId, revision, providerTraceId?, status(pending/approved/rejected/error), reasonCode?, createdAt | providerTraceId 唯一（有值时）；targetType + targetId + revision |
| media_assets | id, ownerPrincipal, purpose, cloudPath, privateFileId, publishedFileId?, status(uploading/private/reviewing/published/deleting/deleted), size, mime, referencedBy[] | ownerPrincipal + createdAt；cloudPath 唯一 |
| mutation_requests | id, principal, action, requestId, payloadHash, result, expiresAt | principal + action + requestId 唯一；过期清理 |
| admin_audit_logs | id, operatorUid, action, targetType, targetId, reason, createdAt | operatorUid + createdAt；targetId + createdAt |

`membershipStatus`：pending/active/posting_disabled/disabled。activeCount 包括 active 和 posting_disabled，不包括 pending/disabled。恢复成员也占名额；后台账号不占小程序成员名额。

权限默认值：pending 仅可查看自己的身份/申请状态；active 可使用本人云日记及社区；posting_disabled 可读取社区、管理本人私人记录及撤回已有公开内容，但不得新发布、评论或点赞；disabled 禁止访问成员云内容。公开课程及已存在的本人本地核心体验不因社区待批准而被阻塞。所有限制在服务端执行。

`localSourceKey` 是首次显式分享时本地生成并持久化的随机映射键，配合真实 ownerId；不使用会重复的演示 recordId 作为全局键。不上传现有 Record 的 userId/OpenID 字段。

## 4. 帖子状态与一致性

`status`：draft / pending / published / rejected / unpublished / hidden / deleted。`desiredPublished` 表示作者是否仍想公开；`moderationHold` 表示管理员禁止公开，两者独立。

| 操作 | 结果与条件 |
|---|---|
| 首次同步 | 检查源记录归属，创建固定 postId，冻结待审版本，pending |
| 审核通过 | 仅当回调版本仍为当前版本、desiredPublished=true、无管理限制且源未删除时 published |
| 拒绝/审核服务异常 | rejected 或保持 pending 并标记审核异常；绝不默认通过 |
| 已发布内容编辑 | 新版本进入 pending，旧版本立即对成员隐藏；计数不清零 |
| 取消同步 | desiredPublished=false，unpublished；迟到回调不可复活帖子 |
| 管理员隐藏 | moderationHold=true，hidden；作者再同步也不得解封 |
| 管理员恢复 | 解除 hold 后重新检查当前审核、作者意愿和源记录状态，不能强制恢复已撤回内容 |
| 删除源/帖 | deleted，停止读取/互动，提交媒体清理；逻辑删除幂等且不可被审核回调恢复 |

每次写及读取详情都核查源、帖子与成员状态。对精选引用逐个解析当前公开原帖，返回作者显示信息和原帖入口；隐藏源无需等待批量更新即可使引用不可见。精选不复制成员图片进入新的永久公开地址。

列表和详情调用统一可见性服务；不能只过滤列表却允许按 ID 查看隐藏详情。评论/点赞的前置可见性判断与计数更新在同一事务或受相同版本约束的原子操作内完成。

## 5. 成员接口（云函数逻辑动作）

成功统一 `{ok:true,data,requestId}`，错误统一 `{ok:false,error:{code,message,retryable},requestId}`。列表统一 `{items,nextCursor}`。客户端不得把错误当空成功。

| 动作 | 入参 | 返回与规则 |
|---|---|---|
| identity.ensureMember | 无身份参数 | id, nickname, membershipStatus, revision；不自动批准 |
| identity.updateNickname | nickname, requestId, expectedRevision | 更新公开昵称；不修改档案完成标记；内容校验 |
| courses.list/get | sense?, cursor?, courseId? | 仅已发布元数据/版本；不暴露草稿 |
| media.prepareUpload | purpose, count, metadata[], requestId | 本人限时上传凭据/目标；格式与额度限制 |
| media.finalizeUpload | assetId, requestId | 服务端检查真实文件大小/类型/归属；返回可引用 assetId |
| journals.list/get | cursor? / journalId | 仅本人含私密内容 |
| journals.save | journalId?, title, body, assetIds[], expectedRevision?, requestId | 保存私人记录；如已同步，事务创建待审新版本 |
| journals.delete | journalId, expectedRevision, requestId | 原记录与关联帖子不可见，后续清理图片 |
| shares.upsertExperience | localSourceKey, 允许的展示字段, expectedRevision?, requestId | 本人体验分享副本；不增加成长次数 |
| posts.setPublication | sourceType, sourceId, sourceRevision, desiredPublished, expectedPostRevision, requestId | postId, status, revision；首次 expectedPostRevision=null，之后使用帖子 revision；校验源版本再发布，不传任意公开字段 |
| posts.list/get | cursor? / postId | 已批准成员；统一可见性；返回显示名、官方标识、本人点赞状态、计数 |
| posts.setLike | postId, liked:boolean, requestId | liked, likeCount；目标状态幂等，不用 toggle |
| comments.list/create/delete | postId + cursor? / postId + body + requestId / commentId + requestId | 单层、分页、审核；删除只允许本人或有治理权限的管理员 |

分页使用签名/校验游标（排序元组与筛选条件），单次上限 20，客户端按 ID 去重；禁止客户端任意设置无限 pageSize。单用户短时间发布和评论应有限速，默认值在实现时集中配置并测试。

## 6. 后台接口与鉴权

后台登录使用云开发支持的托管身份认证；部署前用真实环境验证账号密码登录能力。若账号条件不支持，汇报选项后调整登录入口，不实现绕过登录的万能密码。服务端验证签名、过期与 admin_roles；小程序 OpenID 不能被当成网页管理员 UID。

| 权限 | 动作组 | 关键规则 |
|---|---|---|
| content_admin / super_admin | admin.posts.list/get/hide/restore/delete | 查看公开与待审内容，操作理由必填 |
| content_admin / super_admin | admin.officialPosts.save/publish/unpublish/pin | 从服务端绑定官方账号，审核、版本与幂等一致 |
| content_admin / super_admin | admin.comments.createOfficial/editOfficial/deleteOfficial/moderate | 仅编辑官方正文，不能篡改成员评论；编辑重审 |
| content_admin / super_admin | admin.featured.searchSources/save | 只可选择公开成员帖，来源解析实时检查 |
| super_admin | admin.courses.list/saveDraft/publish/offline/archive/setDefault | 使用 expectedRevision；发布版本不可变；不能下架唯一有效默认课 |
| super_admin | admin.members.list/approve/disable/restrict/restore | 容量事务；不能仅靠前端隐藏按钮 |
| super_admin | admin.roles.grant/revoke | 禁止撤销最后一位有效超级管理员；写审计 |
| super_admin | admin.audit.list | 只读操作日志；无前端编辑/删除能力 |

后台列表只读取职责内的数据，严禁默认返回整个 users 档案或私密 journal_entries。首位管理员由环境所有者通过可信部署步骤绑定，不能提供公开自助升级管理员接口。

## 7. 图片权限与清理

私人图片与公开待展示图片采用隔离路径/资源权限，`private/owner/...` 路径本身不是权限。私密资产仅本人及执行必要处理的服务端可读；社区读图必须核查已批准成员和当前帖可见性。

不能通过把整个云存储设为“所有人可读”解决社区显示。读取代理或短效授权地址由实施验证选择；撤回后立即停止发放地址，旧短效地址有效期上限 5 分钟，已下载的文件无法远程收回。界面撤回提示应准确。

后台课程公开资源与个人图片分目录、分权限，课程图不授予操作私人图片的能力。审核回调必须验来源且防重放，核查目标版本，不能用用户提交的“审核通过”字段。

图片上传完成不等于记录保存。孤立文件建议 24 小时后清理；删除先使内容不可读，再异步删除未引用文件，有失败重试。精选只引用原帖，清理时不把引用视为永久保留私密原图的理由。

## 8. 必须验证的契约

1. 两个账号读取相同公开帖子，不能读对方私密日记、未发布图片或待审评论。
2. 伪造 ownerId/admin role/official 标识被拒绝。
3. 同一发布请求重试、同一帖子点赞重复请求、删除重试结果一致。
4. 点赞数等于唯一点赞关系数；评论数只含已审核且未隐藏删除的评论。
5. 撤回、隐藏、删除与迟到审核回调竞争，内容不复活；精选引用同样不可读。
6. 课程改版、下架不破坏旧会话；新会话只取得可用已发布版本。
7. 日记、发帖、评论都不改变成长统计。
8. 31 人批准边界与并发批准安全；禁止发布与停用权限准确。
9. 旧本地示例不自动认领，账号切换不串数据；云构建拒绝自动重置开关。
10. 管理端无权限、过期登录、最后超级管理员撤销、重复官方发布均正确处理。
