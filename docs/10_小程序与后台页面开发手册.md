# v1.3 小程序与后台页面开发手册

> 初版 2026-09-14。2026-09-15 已完成本地页面实现与浏览器全流程，真实云/真机验证待完成，见 [运行与验收说明](12_社区后台运行与验收说明.md)。依据 [PRD v1.3](product/园艺疗法小程序_PRD_v1.3_社区与后台增量修订.md) 与 [云端契约](09_云端数据与权限契约.md)。

## 1. 小程序页面

保留原 P01–P14 和 5 个 Tab；新增页为非 Tab。所有动态 ID 在跳转时编码，读取时校验；缺少或无效 ID 提供返回入口。

| 页面 | 路由 | 本轮行为 |
|---|---|---|
| P08 五感花园 | /pages/garden/index | 云模式读已发布课程，保留五类感官；准备中课程不能开始任务 |
| P09 课程详情 | /pages/course/detail?id=courseId | 展示发布版；点击开始固定版本，仅以 sessionId 跳转 P10 |
| P10 体验任务 | /pages/experience/task?sessionId=... | 读取当前会话快照；不随后台草稿/发布变化 |
| P11 自然印记 | /pages/imprint/detail?recordId=... | 保留同一 Record 展示，新增分享预览/同步状态入口 |
| P12 记录 | /pages/records/index | 新增右上 `+`、全部/体验/日常筛选、类型标签、每条记录的同步选项 |
| P13 我的 | /pages/mine/index | 云身份/成员状态、公开昵称一致性；成长和最近评估仍受原规则约束 |
| P14 社区 | /pages/community/index | 双列瀑布流、置顶/官方标签、点赞数评论数、分页与刷新 |
| P15 日记编辑 | /pages/journal/edit?journalId=可选 | 新建或编辑；标题、正文、1–3 图、私人保存、同步选项 |
| P16 日记详情 | /pages/journal/detail?journalId=... | 本人私密详情、图片预览、编辑、删除、社区状态及撤回 |
| P17 帖子详情 | /pages/community/detail?postId=... | 公开内容、精选引用、点赞、单层评论；本人删除评论 |

P01–P07 不重新设计；如云身份隔离要求接入初始化，集中在身份/适配层完成，不改变问卷公式和顺序。真正无法规避的页面调整须列出影响和回归证据。

## 2. P12 记录页布局与状态

顶部：标题“我的自然旅程”，右侧 `+`，可触区域至少 44px 等效尺寸。保持成长汇总原位置。

下方：分类切换与混合列表。体验卡显示课程、心情、时长；日记卡显示首图、标题、文字摘要、时间；每卡菜单提供“同步上传社区 / 查看社区帖子 / 取消同步”，按状态呈现。

选择体验卡仍进入 P11，选择日记卡进入 P16；不得把 journalId 传给 P11。筛选不改变成长统计。

体验和日记各自加载：云日记失败时，保留本地体验记录，并显示日记重试条；不能让整个记录页空白。全部列表只合并已加载条目，加载更多维持两源游标并按时间排序。

## 3. P15/P16 编辑与详情

- 默认私密，首次打开有明确“仅自己可见”。取消编辑返回原页面，不提交内容。
- 逐张上传显示进度、失败、重试和移除；图片没上传完成时禁止发布，但保留输入以便重试。
- 新日记保存成功返回 P16；开启同步时先保存私密源再请求发布。发布失败显示“记录已保存，社区发布未成功”，可单独重试。
- 编辑已同步内容，保存后社区进入重新审核；保存前说明该影响。
- 点击删除前显示是否已有社区内容；云端确认撤回后更新页面。删除失败不能先从列表永久移除。
- P16 非作者访问返回不可访问，不依赖 UI 是否有入口。

P11 分享使用当前页内预览区/弹层即可，不新增第二套印记详情。私密字段不进入预览，不因点击分享自动把整个 Record JSON 上传。

## 4. P14/P17 社区

瀑布流图片按宽高比布局，限制极端高图；卡片统一圆角、自然色板，首屏显示加载占位，长标题两行截断。官方标识显示在作者旁。

社区内保留一个“写记录”入口跳 P15。帖子详情有稳定返回路径；点赞展示操作中状态与失败恢复，不能持续虚增数字。

评论输入与列表同页，发送后显示“审核中”仅本人可见；过审后公共列表和计数更新。单层按创建时间正序分页展示。键盘、安全区与长文滚动要真机验证。

成员待批准、禁止发布、停用、空列表、网络失败、帖子已撤回/隐藏均用独立状态文案。官方评论和普通评论同列表展示，官方标签由服务端返回。

## 5. 后台页面清单

后台 URL 与小程序路由独立；部署域名待云环境确定。

| 后台页面 | 建议路径 | 必备内容 | 权限 |
|---|---|---|---|
| 登录 | /login | 账号密码、登录错误、过期后返回登录、退出登录 | 已授权管理员 |
| 课程列表 | /courses | 分类、状态、排序、默认推荐、创建、编辑、下架/归档 | 超级管理员 |
| 课程编辑 | /courses/:id/edit | 标题等全字段、封面/步骤图片、校验、保存草稿、预览、发布 | 超级管理员 |
| 社区帖子列表 | /community/posts | 作者/时间/状态筛选、公开和待审内容、隐藏/恢复/删除及理由 | 内容管理员及以上 |
| 帖子治理详情 | /community/posts/:id | 图文、审核状态、评论列表、官方评论、处理记录 | 内容管理员及以上 |
| 官方帖子编辑 | /official/posts/:id/edit | 新建/编辑、图片、预览、发布/撤下、置顶、每周精选来源选择 | 内容管理员及以上 |
| 评论管理 | /community/comments | 状态/作者/帖子筛选、上下文、隐藏/恢复/删除 | 内容管理员及以上 |
| 成员管理 | /members | 待批准名单、人数、批准/禁发/停用/恢复 | 超级管理员 |
| 管理员管理 | /admins | 授予/撤销角色、停用、最后超管保护 | 超级管理员 |
| 操作记录 | /audit | 操作者、时间、对象、理由，分页 | 超级管理员 |

新建官方帖可用 `/official/posts/new/edit`，路由匹配优先识别 new。编辑器首次保存取得真实 ID。

后台基于电脑表单和列表，课程预览采用与小程序一致的数据结构。后台发布按钮展示当前课程/帖子状态、保存与发布区别；多人编辑冲突提示刷新，不能无声覆盖。

## 6. 共同验收标准

- 小程序维持米白/自然绿风格；后台以易操作为目标，官方贴预览保持小程序视觉关系。
- 任何发布、删除、审核中的状态文案与云端真实结果一致。
- 原五个 Tab 顺序不变，新增页面和后台不能阻塞已有核心体验路径。
- 真机测试图片选择/预览、键盘、长评论、分页、弱网、重复点击、返回恢复。
- 验收记录须区分“代码审查”“脚本验证”“微信真机/后台浏览器验证”；不能将前两项写作已经真实点击通过。
