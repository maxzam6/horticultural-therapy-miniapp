# 园艺疗法微信小程序

护理学院大创项目的展示型微信小程序。当前目标是用一个完整、漂亮、可演示的小程序展示园艺疗法数字化体验流程。

## 当前阶段

- 产品版本：PRD v1.2
- 开发方式：两人协作
- 默认模式：Mock 数据优先、页面先完成、微信云开发后接入
- 产品性质：非公开、非商业化、答辩展示型 MVP

## 唯一答辩流程

```text
扫码进入 → 首页 → 开始体验 → 自然档案 → 状态探索 → 状态报告
→ 五感花园 → 多肉种植体验 → 体验任务 → 自然印记 → 记录 → 我的
```

其他功能、后端接入或素材缺失不得阻塞该流程。

## 本地启动

推荐环境：

- Node.js 20 LTS（仓库提供 `.nvmrc`）
- pnpm 11
- 微信开发者工具

```bash
pnpm install
pnpm dev:mp-weixin
```

生产构建验证：

```bash
pnpm build:mp-weixin
```

构建产物位于 `dist/build/mp-weixin`，使用微信开发者工具导入该目录即可运行。正式真机体验前，在 `src/manifest.json` 的 `mp-weixin.appid` 中填写项目 AppID；不要提交 appSecret 或本地私有配置。

## 当前源码状态

- uni-app Vue 3/Vite 工程已初始化。
- 14 个 PRD 页面路由与 5 个 Tab 已注册。
- 全局自然色板、公共页面壳和基础样式已建立。
- Pinia 用户、评估、体验 Store 已建立。
- Mock 用户、10 道状态探索题、5 个课程和示例记录已建立。
- 统一导航和 Mock Data Adapter 已建立。
- 页面当前为可编译、可导航的工程骨架，具体业务功能按开发任务文档继续实现。
- 第三阶段公共基础设施已冻结；当前进入第四阶段 P01–P08 第一周可运行 Demo 开发。

## MVP 边界

- P0-A：完成首页至自然印记的核心体验闭环。
- P0-B：完成记录和我的基础版。
- P0-C：社区仅保留「自然分享空间，未来开放」占位。
- 不先开发后台、Express/MySQL、复杂登录或真实社区。
- 状态探索仅用于产品体验反馈，不属于医学诊断或正式量表。

## 第一周目标

在无真实后端条件下稳定运行：

```text
首页 → Mock 开启体验 → 自然档案 → 评估介绍
→ 10 题状态探索 → 状态报告 → 探索主页 → 五感花园
```

具体执行任务、文件所有权、依赖关系与验收门槛见 `docs/05_第四阶段第一周可运行Demo任务单.md`。
