# 园艺疗法微信小程序

护理学院大创项目的展示型微信小程序。当前目标是用一个完整、漂亮、可演示的小程序展示园艺疗法数字化体验流程。

## 当前阶段

- 产品版本：PRD v1.2
- 开发方式：两人协作
- 默认模式：Mock 数据优先、页面先完成、微信云开发后接入
- 产品性质：非公开、非商业化、答辩展示型 MVP

## 唯一答辩流程

```text
扫码进入 → 首页 → 开始体验 → 自然档案 → 状态探索 → 状态报告
→ 五感花园 → 多肉种植体验 → 体验任务 → 自然印记 → 记录 → 我的
```

其他功能、后端接入或素材缺失不得阻塞该流程。

## 本地启动

推荐环境：

- Node.js 20 LTS（仓库提供 `.nvmrc`）
- pnpm 11
- 微信开发者工具

```bash
pnpm install
pnpm dev:mp-weixin
```

生产构建验证：

```bash
pnpm build:mp-weixin
```

构建产物位于 `dist/build/mp-weixin`，使用微信开发者工具导入该目录即可运行。正式真机体验前，在 `src/manifest.json` 的 `mp-weixin.appid` 中填写项目 AppID；不要提交 appSecret 或本地私有配置。

## MVP 边界

- P0-A：完成首页至自然印记的核心体验闭环。
- P0-B：完成记录和我的基础版。
- P0-C：社区仅保留「自然分享空间，未来开放」占位。
- 不先开发后台、Express/MySQL、复杂登录或真实社区。
- 状态探索仅用于产品体验反馈，不属于医学诊断或正式量表。
